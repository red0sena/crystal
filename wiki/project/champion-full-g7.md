# g7 전체 학습 준비와 Mind2Web 추가

목표는 1B 이하 텍스트·비전 모두 1위다. 완료된 부분 학습은 텍스트 131,072행·이미지 32,768행으로, 공개 지수가 각각 35.19·48.20이었다. 이것은 g7 전체 학습 결과가 아니다.

사용자 요청에 따라 다음 후보는 g7 원본 999,961행을 핵심 데이터로 사용하면서 취약 과제를 별도로 보강한다. 출처별 표본 제한을 없애고 기존 평가·dev 중복 검사와 라벨 출처 규칙을 유지한다. 11월5일에는 길이 전수 점검·GPU 실측·실행기 검증을 마치고 본학습을 시작했다. 현재 실행과 수정 후 입력 수는 [전체 LoRA 학습 기록](champion-full-lora-v3.md)이 기준이다. 아래 입력 표는 최초 준비 시점의 수치다.

## 완료된 v2 공개 평가가 정한 보강 우선순위

텍스트 비교값은 GLiClass 저자 공개 예측을 공식 채점기로 다시 채점한 값이며 새로운 전체 로컬 GLiClass 실행 결과가 아니다. 비전 비교값은 QEV의 로컬 전체 평가다. 서로 다른 지표(정확도/F1)를 하나의 정확도라고 부르지 않는다.

| 과제 | 우리 | 비교 모델 | 지표 | 공개 지수 격차 기여 |
|---|---:|---:|---|---:|
| PhishNChips | 53.50% | 93.40% | accuracy | 2.42 |
| VAST | 43.99% | 73.05% | macro-F1 | 1.20 |
| iSarcasmEval | 23.53% | 51.09% | English Task-A F1 | 0.97 |
| WinoGrande | 61.64% | 80.19% | accuracy | 0.96 |
| ANLI | 43.55% | 61.71% | macro-F1 | 0.90 |
| HellaSwag | 63.66% | 82.80% | accuracy | 0.84 |
| Mind2Web | 49.33% | 83.35% | accuracy | 4.65 |

KIE(CORD+FUNSD)는 정확도96.06%로 QEV95.01%보다 높다. v1에서 컸던 문서 추출 격차를 최신 결과에도 그대로 적용하지 않는다. 이번 비전의 우선 보강은 Mind2Web이다. 피싱은2,000개 중1,928개를 legitimate로 골랐고, noul 정확도도54.9%여서 한 형식만의 실패로 결론 내리지 않는다. 이메일의 표면 문체와 URL 위험 신호의 분포 차이도 가능한 원인이며, 새 보강의 실제 효과는 학습 후 확인해야 한다.

집계 원본은 `runs/champion-v1/full-g7-v3/enrichment-weakness-analysis.json`과 `enrichment-format-diagnostics.json`이다. 개별 평가 오답·선두 예측을 학습 라벨로 옮기지 않았다. 공개 결과를 개발에 사용했으므로 후속 공개 평가는 blind 확인이 아니다.

## 텍스트 보강 내용

- 피싱: 기존에 일부만 사용했던 Nazario_5·Nigerian_5의 사람 라벨 원본 풀을 확대한다. 전체 이메일과 실제 관측된 URL에서 추출한 hostname을 사용하고 분류형·긍정형·부정형을 함께 만든다. 이 추가분에서 일반 스팸 양성을 전부 피싱이라고 다시 이름 붙이지 않는다. 기존 g7 핵심에는 과거 스팸/사기 분류가 포함되어 있으므로 의미 차이가 모두 해결된 것은 아니다.
- 영어 풍자: iSarcasmEval train의 영어 Task A를 별도 보강한다. 같은 원본 사실의 choice/noul 양방향 질문을 만들며, 아랍어·category B의 많은 질문이 영어 풍자 판별의 표본 수인 것처럼 계산하지 않는다.
- 입장: VAST의 허용된 전체 train+dev 원본에서 g7 표본에 빠졌던 사례를 보완한다. 사람들의 표가 갈리는 항목의 원래 target을 보존한다.
- NLI: WANLI의 사람 판정 train 전체 풀(원본102,885행)을 대상으로 한다. 기존 capped pool보다 넓게 읽고 중복·heldout·오염 필터를 적용한다. ANLI 시험 문항은 사용하지 않으며, 과거 위키에서 제외한 ANLI 학습 출처를 조용히 추가하지 않는다.
- 상식: HellaSwag train과 WinoGrande xl train의 기존 표본에 빠진 허용 사례를 추가한다. 원본 정답과 오답 선택지를 유지한다. HellaSwag validation은 중복 제외에만 사용하며 그 라벨을 학습하지 않는다.

추가 질문은 원본 문항 수와 구별한다. 같은 이메일의 세 질문을 세 개의 독립 이메일이라고 세지 않는다. 전체 입력이 같은데 target이 충돌하는 그룹은 원본까지 함께 격리한다. 새로운 모델 교사 호출·리랭킹 손실은 없다.

### 별도 URL 근거 데이터

[pirocheto/phishing-url](https://huggingface.co/datasets/pirocheto/phishing-url)의 train만 사용한다. 고정 revision은 `1375d450d4540205ac11781b807249c9509739cd`이며 train 원본은7,658 URL이다. [원 논문4.1절](https://arxiv.org/html/2010.12847v1#S4.SS1)에 따르면 피싱 URL은 Phishtank/Openphish, 정상 URL은 Alexa/Yandex 수집에서 왔다. 새 모델이 라벨을 만든 데이터가 아니며 외부 수집 목록에 따른 라벨을 `programmatic`으로 명시한다.

모델 입력에는 URL와 거기서 파싱한 hostname만 넣는다. 원본의87개 특징 중 웹페이지 내용·WHOIS·검색 색인·평판 수치 등을 주입하지 않는다. 알려진 공개/기존 dev의 URL·hostname 및 기존 텍스트 오염 필터를 적용하고 새 URL 출처 안에서는 hostname 단위로 train/dev를 나눈다. 이 분할은 registrable domain 분할이나 모든 기존 g7 데이터에 대해 새로운 hostname이라는 보장은 아니다. 과거 웹사이트 상태 라벨을 이메일 전체의 안전 라벨이나 현재 URL의 안전 보장으로 바꾸지 않는다.

이 과제를 로드할 때는 `new-source-registry.json`의 새 출처 등록을 학습 실행기에 명시적으로 반영해야 한다. 기존 g7 전용 출처 검사기를 우회해 unknown source를 통과시키지 않는다.

## Mind2Web

기존 화면 요소 선택 변환기를 재사용한다. 고정 원본은 `osunlp/Multimodal-Mind2Web@1b4c6a8cf9f77b7a5e0d641959935c80c4a05889`의 train 27개 shard, 7,775개 행동이다. 표본 수 제한 없이 전부 읽고, 정답과 충분한 오답 요소가 보이는 행동을 선택형 문제로 변환한다. 박스 A–D가 이미지에 그려져 있으므로 선택지 순서를 보존한다. 공개 평가에서 검증한 Arial Bold 폰트를 사용한다.

같은 작업(annotation_id) 또는 같은 원본 화면을 공유하는 행동은 같은 그룹으로 묶는다. 공개 평가의 action/task ID, 전체 공개 이미지·기존 진단 이미지·과거 이미지 dev와의 SHA256 및 dHash 거리 4 검사 후 그룹 전체를 제외한다. 새로운 dev도 그룹 단위로 분리하고 train과의 근사 이미지 중복을 추가로 제거한다. 이 이미지 필터는 모든 크롭·편집 중복의 부재를 증명하지 않는다. train 화면에는 원본 렌더링 오류가 있을 수 있다.

실행 코드는 `qwen_decision/v3/champion_full_mind2web.py`, 서비스는 `champion-full-mind2web-v3`다. 실제 상태와 완료 시의 train/dev 행 수는 다음 파일이 기준이다.

- `runs/champion-v1/full-g7-v3/mind2web-status.json`
- `runs/champion-v1/full-g7-v3/mind2web-prepared.json` — 준비 완료 후 생성
- `runs/champion-v1/full-g7-v3/data-plan.json` — 전체 학습 입력 계획, 아직 학습 실행기 아님

Mind2Web 단독 준비 결과는 train3,604행/dev1,282행이다. 기존14개 이미지 출처의 **캐시된 후보 풀 전체**와 합칠 때 새로 예약한 dev와 다시 대조하면 최종 이미지 학습에는 Mind2Web3,328행이 남는다. 전체 이미지 학습 구성은55,656행이다. 캐시된 풀에는 과거 변환 단계의 상한이 있으므로 모든 원본 이미지 데이터셋을 전수 사용했다고 부르지 않는다. 최종 구성은 `enriched-vision-prepared.json`이 기준이다.

## 검색 데이터와 리랭킹의 구분

사용자 결정(2026-11-05): 현재 모델은 하나의 답을 선택하므로 후보 전체의 순서를 맞히는 리랭킹 손실을 새로 넣지 않는다. 검색 데이터를 쓰더라도 질의와 후보 중 가장 관련 있는 답을 고르는 선택형 CE에 맞춘다. 여러 관련 문서가 존재한다면 정답 하나 외의 문서를 무조건 오답으로 만들지 않는다. 실제 관련도 판정과 기존 다중 정답 처리 규칙을 확인해야 한다. 새 검색 원본이나 리랭킹 손실은 이 변경에서 추가하지 않았다.

완료된 v2 학습 파일을 직접 확인한 결과:

| 출처 | 학습 파일 행 수 | 실제 과제 |
|---|---:|---|
| ESCI | 1,956 | 질의·상품 한 쌍을 Exact / Substitute / Complement / Irrelevant로 분류 |
| kv-lookup | 978 | 주어진 키의 값을 선택; 문서 관련도 판정 아님 |

ESCI는 관련도 신호를 제공하지만 여러 문서의 순서를 직접 학습한 것은 아니다. g7 전체 ESCI 출처는 7,804행이다. 문단 찾기 변환 코드는 저장소에 있지만 현재 g7/v2 학습 파일에는 해당 출처가 없었다. 앞선 대화에서 실제 학습에 들어간 것처럼 설명한 부분을 정정한다. 근거는 `runs/champion-v1/full-g7-v3/reranking-coverage.json`이다.

작업 그룹·공유 화면 분리와 평가 중복 그룹 제외에 대한 3개 단위 검사가 통과했다. 실제 전체 변환·중복 검사 결과는 완료 파일로 별도 확인한다.

보강 코드의 교차 형식 라벨 일관성·순서가 보장된 제한 병렬 처리·URL에서 외부 특징을 제외하는 검사도 통과했다. 6개 텍스트 변환기는 실제 복구 원본의 처음3행을 생성하고 schema/target을 확인한 기록이 `enrichment-builder-smoke.json`에 있다. 이 검사는 학습 성능 검증과 구별한다.

## 11-05 준비된 최종 입력

| 구성 | 학습 행 수 | 구분 |
|---|---:|---|
| g7 핵심, 전체 원본에 필터 적용 후 | 946,080 | 출처별 표본 제한 없음 |
| 피싱 이메일 보강 | 21,456 | 원본 라벨의3가지 질문 형식 |
| 영어 풍자 Task A 보강 | 10,224 | 원본 라벨의3가지 질문 형식 |
| WANLI 보강 | 102,308 | 사람 판정 train 전체 풀에서 필터 적용 |
| VAST 보강 | 6,046 | 기존 g7와 동일한 의미 입력 중복 제외 후 |
| HellaSwag 보강 | 12,992 | 기존 g7와 동일한 의미 입력 중복 제외 후 |
| WinoGrande 보강 | 13,605 | 기존 g7와 동일한 의미 입력 중복 제외 후 |
| URL 보강 | 17,835 | 5,945 URL ×3가지 질문 형식 |
| **텍스트 합계** | **1,130,546** | 원본 문항 수와 다름 |
| **이미지 합계** | **55,656** | Mind2Web3,328행 포함 |

텍스트 기본 파일은 `mix/text-train.jsonl`(1,112,711행), URL 추가 파일은 `mix/phishing-url-train.jsonl`(17,835행)이다. 두 파일을 읽어야 위 합계가 된다. 첫 번째 파일 하나만 읽으면 새 URL 과제가 빠진다. URL 검증은1,406 URL/4,218행, 이미지 검증은11,417행이다. 원본 g7 dev도 별도로 보존한다.

동일 입력에 target이 충돌한12개 그룹은 원본까지 제외했다. 추가분의 동일 입력·동일 정답 중복도 제거했다. 최초 준비 manifest와 파일 해시 검증 결과는 `runs/champion-v1/full-g7-v3/input-manifest.json`이 기준이다.

학습 직전 추가 길이 검토에서 새 이메일 보강의65,536토큰 초과3개 원본·9개 질문을 별도로 보관했다. g7 핵심946,080행은 그대로다. 따라서 실제 학습은 텍스트 **1,130,537행**, 이미지 **55,656행**이며 최장 텍스트49,552토큰도 GPU에서 역전파·optimizer step을 통과했다. 최종 입력·코드 해시는 `runs/champion-v1/full-g7-lora-v3/plan.json`에 고정했다. 본학습은 진행 중이며 성능 재평가는 학습 완료 후 자동 실행한다.
