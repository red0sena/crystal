# 원본 Qwen 공동 학습 파일럿

고정 seed 1개, 텍스트16,384 + 이미지16,384 문항, CE 2,048 update의 탐색 결과다. 공식 보드 점수나 순위가 아니다.

| 평가 | 원본 정확도 | 저장·복원한 공동 모델 정확도 | 변화 (%p) |
|---|---:|---:|---:|
| text-dev | 47.60% | 66.82% | +19.22 |
| image-dev | 75.78% | 86.33% | +10.55 |
| text-diagnostic | 43.09% | 63.01% | +19.92 |

표는 출처 평균 정답률이며 F1·nDCG·공식 Full을 재현하지 않는다. 기존 diagnostic은 이미 관찰한 평가다.

회전 정렬은 학습에 쓰이지 않은 실제 이미지와 사람 서술로 별도 검증했다. 이 단계는 판단 출력에 적용하지 않았다.
정렬 평가 63쌍에서 cosine은 0.0228 → 0.1450, shuffled 대조는 -0.0949다. 기하 개선만으로 판단 정확도 향상을 추론하지 않는다.

기본 가중치는 고정한 공식 원본이고 기존 Crystal/QEV 가중치를 사용하지 않았다. ViT는 동결했다. 어댑터 병합 후 전체 평가를 다시 했으며 저장·복원 로그 일치를 확인했다.

전체 비전 보드의 근사 중복 검사는 아직 완료되지 않아 제출용 최종 학습으로 취급하지 않는다. 두 트랙의 공식 1위 목표는 아직 달성하지 않았다.

상세 결과: [JSON](champion-joint-pilot-results.json). 설계·계보: [프로젝트](champion-v1.md). 실행: `runs/champion-v1/joint-g7-v1/`.

## 기존 Crystal과 같은 문항 비교 및 다음 단계

완료 후 기존 `inference-policy-v1`의 base 예측과 ID·gold를 직접 맞췄다. 기존 Crystal은 이미지 학습 전 `wise80-g6-g7e2`다. 모델을 다시 실행하지 않고 보존된 native 예측을 재사용했다. 두 조건의 입력 형식은 같은 d3이고, 기록에 있는 같은 문항을 대상으로 한다. 아래는 calibration을 포함한 전체 diagnostic의 출처 평균 정확도다. 원래 inference-policy의 evaluation 부분집합 점수와 섞지 않는다.

| 전체 diagnostic | 기존 Crystal | 이번 공동 파일럿 | 차이 (%p) |
|---|---:|---:|---:|
| 텍스트1,335문항 | 70.88% | 63.01% | −7.87 |
| 이미지2,184문항 | 61.92% | 59.62% | −2.30 |

원래 evaluation 분할만 맞추면 텍스트1,079문항은70.81% 대62.15%, 이미지1,737문항은62.38% 대59.31%다. 상세 입력 해시·출처별 점수는 `runs/champion-v1/joint-g7-v1/crystal-comparison.json`에 보존했다. 기존 Crystal의 학습량·데이터·merge가 다르므로 이 격차만으로 공동 학습의 간섭이나 LoRA의 열세를 확정하지 않는다.

사용자 재확인에 따라 다음 우선순위는 **텍스트·비전 각 트랙의1B 이하 전체 선두를 넘기 위한 공식 방식 평가와 학습 확대**다. 기존 Crystal과의 비교는 현재 파일럿의 위치를 설명하는 참고 자료다. 위 격차만을 이유로 텍스트 단독16k 대조를 다음 필수 실험으로 지정했던 제안은 철회한다. 간섭 대조는 두 트랙 성능을 올리는 과정에서 구체적인 보존 실패가 관측될 때 설계한다.

현재 후보를 텍스트 F1·nDCG·요청별 exact-match와 비전11개 공식 방식 공개 평가에 연결하고, 선두의 공개된 결과와 같은 척도에서 과제별 격차를 파악한다. 이 격차와 기존 근거로 학습 과제·형식·라벨의 누락을 보완하며 원본에서 시작하는 g7·이미지 학습량을 확대한다. 확대 시 이미지 reserved 그룹을 계속 보호하고 전체 보드의 근사 중복 감사를 완료한다. 공개 점수는 비공개 Full과 구별하며, 양쪽1위 달성 여부는 최종 고정 후보의 공식 비공개 평가로 확인한다.

정렬은 별도의 보조 연구로 둔다. 평가 retrieval R@1은63쌍 중3개(4.76%)로, cosine 개선만으로 실용적인 판단 전이가 확인되지 않았다. 성능 후보를 선택하는 주 지표는 텍스트·이미지 판단 결과이며, 후속 정렬 개입은 회전 유무를 대조해 판단 정확도로 확인해야 한다.
