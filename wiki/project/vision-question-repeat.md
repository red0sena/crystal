# 이미지 한 번 + 질문·선택지 반복 대조

2026-11-04. **평가·검산 완료.** [이전 추론 정책 비교](inference-policy.md)에서 이미지까지 반복했을 때 정확도가 내려간 원인을 좁히기 위한 후속 실험이다. 같은 Crystal 가중치와 같은 이미지 문항·분할을 사용하고, 신경망 추가 학습은 하지 않는다.

## 입력 조건

`QO`는 질문과 선택지다. 모든 새 조건에서 원본 이미지는 각각 한 번만 넣는다.

| 정책 | 입력 순서 | 목적 |
|---|---|---|
| `base` | 이미지 → QO | 기본 입력을 재실행해 점수 재현과 이번 실행 시간을 확인 |
| `q_repeat` | 이미지 → QO → 다시 읽기 지시 → QO | 주 대조. 이전 전체 반복에서 두 번째 `State:`·이미지 블록만 제거 |
| `q_echo` | QO → 이미지 → QO | 보조 대조. 이미지 앞에 질문을 먼저 보여 주는 배치 효과 확인 |
| `image_repeat` | 이미지 → QO → 다시 읽기 지시 → 이미지 → QO | 이전 실행의 전체 반복 결과를 고정 참조로 재사용 |

`q_repeat`는 이전 전체 반복과 비교할 때 두 번째 이미지 상태 블록만 달라진다. `q_echo`는 기존 native echo 양식을 사용하므로, 질문 위치뿐 아니라 답변 마무리 지시의 반복 횟수도 다르다. 둘의 차이를 순수한 위치 효과라고 해석하지 않는다.

## 고정 조건과 평가

- 이전 이미지 2,184문항·8출처를 그대로 사용한다. calibration 447문항, evaluation 1,737문항이며 원래 그룹 분할을 유지한다.
- 새로 실행하는 예측은 3조건 × 2,184 = 6,552개다. 텍스트 문항은 이번 대조에서 재실행하지 않는다.
- 이전 기본 입력 길이가 3,000토큰 이하인 경우에만 반복을 적용하는 규칙을 유지한다. 원래 이미지 평가에서는 모든 문항이 이 조건을 만족했다. 입력을 자르지 않는다.
- 체크포인트, BF16 연산, native system/chat 양식, 마지막 위치의 선택지 코드 logit readout을 고정한다. 문항마다 조건 실행 순서를 순환한다.
- 주 지표는 evaluation의 출처별 정확도를 동일 가중한 macro 평균과 NLL이다. 원시 확률과 calibration으로 따로 맞춘 temperature의 보정 확률을 함께 기록한다. 양의 temperature는 정답 선택을 바꾸지 않는다.
- 차이의 95% 구간은 고정된 각 출처 안에서 그룹을 짝지어 5,000회 bootstrap한다. 다중 비교 보정은 하지 않는다. 모델·출처·calibration을 고정했을 때의 문항 표본 변동만 반영한다.
- 새 세 조건은 같은 실행에서 시간을 잰다. `image_repeat` 시간은 이전 실행 값이므로 실행 간 환경 차이를 포함할 수 있다. 이미지 파일 읽기와 warmup은 추론 시간에서 제외하고 이미지 읽기는 별도 저장한다.

## 검산과 해석 범위

원본 소스·모델·이전 결과·이미지의 해시를 검사한다. 새 모든 예측의 이미지 토큰 수가 이전 기본 입력과 같아야 한다. 기본 입력은 이전 실행과 전체 예측·logit 차이를 기록하고, 각 출처 한 문항씩 네 조건을 실제 모델로 다시 실행해 검산한다. 저장한 전체 logit에서 정확도·NLL도 별도로 재계산한다.

이전 실패 결과를 본 뒤 설계한 후속 대조이며 이미 확인했던 평가셋이다. 개선이 있더라도 새로운 blind 평가나 다른 모델로의 일반화를 입증하지 않는다. 이미지 중복을 없앴을 때 회복되는지는 볼 수 있지만, 그 자체로 이전 실패가 객체 이중 계수 때문이었다고 확정할 수는 없다.
