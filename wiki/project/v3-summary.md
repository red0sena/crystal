# v3 전체 요약 (2026-10-16 ~ 10-21)

[위키 홈](../README.md) · [목표와 규칙](jev-index.md) · [작업 기록(시간순 상세)](v3-log.md) · [전략](../designs/beat-d3-lite.md) · [평가](../designs/evaluation.md) · [데이터 출처](../designs/phase2-data-sources.md) · [참고 문헌](../resources/references.md)

이 페이지는 v3에서 한 일을 주제별로 묶은 요약이다. 수치는 결과 파일에서 다시 뽑았다. 경위와 세부 수치, 정정 기록은 [작업 기록](v3-log.md)에 있다.

## 1. 목표와 평가

- **목표:** Qwen3.5-0.8B 판정 모델로 Jev Decision Index에서 `vllm-sr/d3-lite`(Full 32.33)를 넘는다. 지수는 대략 Full ≈ 0.2·공개 + 0.506·비공개 same + 0.404·비공개 new − 3.04이고, 80%가 비공개 평가다([규칙](jev-index.md)).
- **평가 지표** (출처마다 skill = max(0, (정확도 − 우연) / (1 − 우연))을 구한 뒤 출처 평균. 우연보다 낮은 출처는 0으로 센다):

| 지표 | 무엇 | 대응 | 파일 |
|---|---|---|---|
| JEVal same / new / 전체 | JEVal 51개 출처를 문서 그룹 단위로 나눈 dev(출처당 60, 2,971문항). same 22개, new 29개 | 비공개 same / new | `runs/proxy/<모델>/summary.json` |
| 공개 샘플 | 공개 0.3 suite에서 벤치마크당 40그룹(2,149행), 키트 채점기 | 공개 20% | `runs/board/score-<모델>/index.json` |
| fresh-v1 | 16개 출처 1,335문항. 15개는 학습·JEVal·index에 없다. GoEmotions는 validation을 쓰는데, test는 JEVal에 있고 train은 g4부터 학습한다("−GE"는 GoEmotions를 뺀 15개 평균) | 선택에 쓰지 않는 일반화 확인 | `runs/fresh/<모델>.json` |
| 정답 dev | 학습 출처에서 그룹 단위로 떼어 둔 dev | 학습 중 모델 선택 | `runs/v3/<run>/eval.json` |
| 순서 편향·망각 | 4순서 채점, 원본 대비 맞힘→틀림 / 틀림→맞힘 | 진단 | `runs/bias/`, `runs/proxy/forgetting-*.json` |

- JEVal restricted 절반(4,926문항)은 최종 후보에만 쓴다. 아직 쓰지 않았다.
- d3-lite 비교는 같은 문항에서 하고, 우리 엔진으로 d3-lite 가중치를 돌려 원본 런타임과 360문항 100% 일치를 확인했다.

## 2. 방침

- **교사에게서 배우지 않는다** (2026-10-17). 학습·dev·모델 선택 모두 정답만 쓴다.
  - 예외: 도구 영역(tools-percall, When2Call, API-Bank)은 생성 모델이 만든 정답을 허용한다.
  - 예외(2026-10-19): MiniCheck C2D/D2C(GPT-4로 만든 근거 문서 사실 확인 데이터, 라벨은 생성 과정에서 정해짐)도 허용한다. 우리 과제에 대한 교사의 답(typed-decisions, SII-Decision 교사 분포)은 여전히 쓰지 않는다.
  - yuri_v3(Jev 1.13 증류)와 openjev_v2(라벨 출처 미확인)는 쓰지 않는다.
- **데이터 출처마다 기록한다.** 모든 출처를 `mix.SOURCES`에 정답 출처(human / programmatic / model)와 원본 항목 키로 등록한다. 미등록이면 빌드가 실패한다.
- **오염 제거:** index·JEVal 문항과 겹치는 학습 행은 빌드 때 뺀다(`decontam.py`).
  - JEVal 과제와 같은 데이터셋은 학습에 쓰지 않는다(FinQA, FEVER, TREC, AIDA 등).
  - 학습에 쓴 lex-glue·CUAD는 JEVal에서 뺐다. GoEmotions는 g4부터 학습해서 따로 표시한다.
- **fresh-v1 보호:** 학습 셋 빌드가 fresh-v1과 같은 상태 텍스트를 뺀다. 2026-10-19부터 정규화 60자 이상 문장이 하나라도 겹치는 행도 뺀다.
- **같은 원문 묶음도 피한다(2026-10-19):** 데이터셋 이름이 달라도 평가셋과 원문을 공유하면 쓰지 않는다(MultiHiertt·TAT-DQA는 FinQA와 같은 연차보고서, Re-DocRED는 HotpotQA 문단, Social Chemistry도 같은 이유로 뺐다). Scruples도 처음엔 fresh-v1 ETHICS와 같은 AITA 글이라 뺐지만, fresh-v1은 ETHICS의 짧은 MTurk 문항만 써서 그 사유를 철회했고 g7은 Scruples를 학습한다([작업 기록](v3-log.md)의 "gold7 학습 전 검토 반영").
- **라이선스:** 비상업(NC) 데이터셋은 학습에 쓰지 않는다(SciQ, ANLI, Financial PhraseBank를 뺐다). **미해결 예외:** LexGLUE SCOTUS 문항은 판결문이 퍼블릭 도메인이지만 쟁점 분야 라벨(SCDB)의 upstream 조건이 CC-BY-NC-3.0이다. 이 문항이 g6에 1,363행, g7에 2,684행 학습됐다. 공개 전 검토 대상이다. "연구 목적으로만" 같은 사용 제한도 같이 본다(ConditionalQA 제외). 라이선스가 불명확한 출처는 표시하고 공개 전에 검토한다(WNED 원 배포처는 라이선스 없음, 사용자 판단 대기).

- 원본을 섞고 나면 g3e2·g4b를 더하는 이득이 없다. 원소별 방법(TIES, SLERP, Model Stock)은 단순 가중 평균보다 낮았다.
- 1위는 [Task Arithmetic](../papers/task-arithmetic.md)(원본 + 0.4·Δg6 + 0.4·Δg7e2)이다. 두 모델은 데이터가 겹쳐 변화량 충돌이 작다(코사인 중앙값 0.29). 그래서 다른 과제 병합용 방법(RegMean, Fisher, CART, CAT)은 미실행으로 두었다. AdaMerging식 층별 계수만 남은 후보다([작업 기록](v3-log.md)의 "병합 방법 검토").
- 22개 중 1위라 점수는 낙관적이다. 순위는 JEVal dev와 공개 샘플로 매겼으므로 두 점수 모두 선택 편향이 있다. JEVal restricted로 아직 확인하지 않았다. 가중치는 상위 3개(원본 20·25·15%)만 남겼다.
- fresh-v1에는 학습한 GoEmotions(validation)가 들어 있다. 이를 뺀 15개 평균(−GE)은 wise80 0.533, wise75 0.522, wise85 0.537, g6 0.459, g7e2 0.452, d3-lite 0.498로, 우위 방향은 같다.

## 6. 진단 결과 요약

- **구조:** causal과 양방향 attention은 같은 조건에서 거의 같았다. 구조는 핵심 변수가 아니다.
- **d3-lite 가중치 감사:**
  - readout은 원본 LM head 행에서 1.1%만 이동했다. 임베딩은 67% 원소가 바뀌었다(앞선 "동결" 추정은 틀렸다).
  - g1은 d3-lite보다 층마다 1.5~2.4배 더 이동했다.
- **순서 편향:** 위치 쏠림은 작다(RStd 0.02~0.04). 4순서 평균의 효과는 1%p 남짓이다.
- **망각과 학습:** 원본 대비 d3-lite와의 순증 차이 대부분은 "덜 새로 맞힘"이다(g1: 212 대 77). 섞기 뒤에는 잊음이 d3-lite 이하로 내려간다.
- **반복 학습:** g3 3에폭에서 dev 손실이 오르고, 틀린 문항을 90% 넘게 확신하는 비율이 5% → 46%로 늘었다. 새 문항으로 1바퀴 돈 g4b에는 이런 양상이 없었다.
- **같은 출처인데 덜 일반화:** WinoGrande는 내부 dev 0.85인데 JEVal 정확도는 0.63이다. 선택지 형식(키 대 설명)은 원인이 아니었다(`format_probe.py`).
- **무관한 선택지 패딩:** 입력 토큰의 약 40%를 차지한다. 패딩을 끈 g4b는 공개 다지선다(SGD, BANKING77, API-Bank)가 떨어졌다. 다만 데이터도 함께 바뀌어 g4a로 확인할 일이다.
- **남은 new 격차(g4b 시기 최선 후보 대 d3-lite):** 금융 예/아니오, 개체 연결(AIDA), 예시 기반 분류(LongBench TREC), 커뮤니티 선호. 중국어 과제와 장문 검색은 동률이고, 여론·가치 판단은 앞선다.
- **데이터 폭의 효과(g6):** 104개 출처로 넓히자 AIDA +0.52(Zeshel: 이름만으로는 23%만 맞는 같은 세계관 후보), TREC +0.32~0.44(예시 기반 분류), HaluEval +0.17~0.30이 올랐다. new 격차가 −0.046(이전 최선) → −0.012로 줄었다.
- **g7 3에폭(2026-10-21):** 에폭 3에서 gold dev KL이 0.51 → 0.87로 뛰어 과적합했다. 에폭 2는 공개 42.04로 단독 최고지만 JEVal same은 g6보다 2.5점 낮다(BoolQ, MMLU-Pro, HaluEval, TruthfulQA 하락). 에폭 1 → 2에서 상식 객관식(gold dev CommonsenseQA·SIQA·ARC, fresh SWAG·QuaRTz·PIQA·COPA)이 내렸다.
- **원본 섞기(2026-10-21):** 같은 원본에서 학습한 두 모델(g6, g7e2)을 평균하고 원본을 20~25% 섞으면 각자보다 JEVal same·new가 모두 오르고 잊음이 준다(원본이 맞힌 문항 중 잊음 21%, d3-lite 24%).
- **데이터 감사가 찾은 결함(2026-10-19):** v3-gold4의 분할 누수(예시 기반 분류 dev 31%, WNED 문서), TAT-QA 증감 변환 오류(주석자의 "이전−이후" 부호), StepGame 원본의 잘못된 템플릿(10,303개 이야기). 모두 고친 뒤 v3-gold5·6을 만들었다.
