이 페이지는 v3에서 한 일을 주제별로 묶은 요약이다. 수치는 결과 파일에서 다시 뽑았다. 경위와 세부 수치, 정정 기록은 [작업 기록](v3-log.md)에 있다.

## 1. 목표와 평가

- **목표:** Qwen3.5-0.8B 판정 모델로 Jev Decision Index에서 `vllm-sr/d3-lite`(Full 32.33)를 넘는다. 지수는 대략 Full ≈ 0.2·공개 + 0.506·비공개 same + 0.404·비공개 new − 3.04이고, 80%가 비공개 평가다([규칙](jev-index.md)).
- **평가 지표** (skill = (정확도 − 우연) / (1 − 우연), 출처별 평균):

| 지표 | 무엇 | 대응 | 파일 |
|---|---|---|---|
| JEVal same / new / 전체 | JEVal 51개 출처를 문서 그룹 단위로 나눈 dev(출처당 60, 2,971문항). same 22개, new 29개 | 비공개 same / new | `runs/proxy/<모델>/summary.json` |
| 공개 샘플 | 공개 0.3 suite에서 벤치마크당 40그룹(2,149행), 키트 채점기 | 공개 20% | `runs/board/score-<모델>/index.json` |
| fresh-v1 | 학습·JEVal·index에 없는 16개 출처 1,335문항 | 독립 일반화 확인 | `runs/fresh/<모델>.json` |
| 정답 dev | 학습 출처에서 그룹 단위로 떼어 둔 dev | 학습 중 모델 선택 | `runs/v3/<run>/eval.json` |
| 순서 편향·망각 | 4순서 채점, 원본 대비 맞힘→틀림 / 틀림→맞힘 | 진단 | `runs/bias/`, `runs/proxy/forgetting-*.json` |

- JEVal restricted 절반(4,926문항)은 최종 후보에만 쓴다. 아직 쓰지 않았다.
- d3-lite 비교는 같은 문항에서 하고, 우리 엔진으로 d3-lite 가중치를 돌려 원본 런타임과 360문항 100% 일치를 확인했다.

## 2. 방침

- **교사에게서 배우지 않는다** (2026-10-17). 학습·dev·모델 선택 모두 정답만 쓴다.
  - 예외: 도구 영역(tools-percall, When2Call, API-Bank)은 생성 모델이 만든 정답을 허용한다.
  - yuri_v3(Jev 1.13 증류)와 openjev_v2(라벨 출처 미확인)는 쓰지 않는다.
- **데이터 출처마다 기록한다.** 모든 출처를 `mix.SOURCES`에 정답 출처(human / programmatic / model)와 원본 항목 키로 등록한다. 미등록이면 빌드가 실패한다.
- **오염 제거:** index·JEVal 문항과 겹치는 학습 행은 빌드 때 뺀다(`decontam.py`).
  - JEVal 과제와 같은 데이터셋은 학습에 쓰지 않는다(FinQA, FEVER, TREC, AIDA 등).
  - 학습에 쓴 lex-glue·CUAD는 JEVal에서 뺐다. GoEmotions는 g4부터 학습해서 따로 표시한다.
- **fresh-v1 보호:** 학습 셋 빌드가 fresh-v1과 같은 상태 텍스트를 뺀다.
- **라이선스:** 비상업(NC) 데이터는 학습에 쓰지 않는다(SciQ, ANLI, Financial PhraseBank). 라이선스가 불명확한 출처는 표시하고 공개 전에 검토한다.

## 6. 진단 결과 요약

- **구조:** 지금까지의 causal/양방향 비교와 동결 backbone·작은 추가 학습 범위에서는 뚜렷한 개선이 없었다. 반복 깊이 등 구조 자체를 충분히 재학습하는 경우까지 결론내리지는 않는다.
- **Pointer 소규모 비교(2026-10-19):** g4b의 같은 backbone에서 head-only 100스텝 + 마지막 2개 층 20스텝을 비교했다. 선택된 dev 출처 평균은 코드 82.18%, Pointer 77.13%(361문항, 47출처). 이번 조건에서는 개선이 없었다. 소규모·단일 seed 결과이며 독립 평가가 아니다. [설정·결과](pointer-pilot.md).
- **논문 기반 구조 검색(2026-10-19):** 층 결합·residual gate·IA3·FFN·층 생략/교환·잔차 Pointer/Set Transformer 등을 99개 설정·seed 조합으로 비교했다. 선택용 +0.37%p였던 최선 후보가 별도 confirmation에서는 78.20%로 기본 78.25%를 넘지 못했고, JEVal restricted 짧은 문맥 부분집합에서도 57.86% 대 기본 58.02%였다. 이번 범위에서 채택할 개선은 확인되지 않았다. [전체 실험](architecture-search.md).
- **입력·추론 변경(2026-10-19):** 추가 14편 조사 후 반복·echo·정의만 사용·prefix·prior 보정 7개 후보를 비교했다. 입력 반복의 selection +0.53%p는 다른 문서 2,573문항에서 −0.89%p(95% 구간 [−1.91,+0.15]%p)로 재현되지 않았다. 채택하지 않았다. 반사실 쌍 목표·R-Drop·반복 깊이는 미학습 후보로 구분했다. [조사·실험](other-methods.md).
- **LM Head 대체 readout·MLP(2026-10-19):** 30,548개 gold 표본으로 6종·24개 설정/seed를 학습하고 선형 readout·512폭 MLP·code 대조군을 마지막 두 층과 함께 추가 학습했다. 별도 2,027문항/34출처의 두 seed 평균은 기본 79.40%, 새 선형 77.97%, MLP 79.28%(head-only 79.34%)였다. MLP의 seed별 차이 −0.29/+0.04%p 구간이 모두 0을 포함해 개선으로 채택하지 않았다. [설계·결과](readout-mlp.md).
- **완료된 g6와 가중치 조합 재구성(2026-10-19):** 작업 중 Hub revision a0b44b4의 완료본을 발견해 g6 67% + g3 2에폭 33% recipe를 로컬에서 만들었다. 같은 fresh-v1에서 GoEmotions를 뺀 15출처/1,235문항의 출처 평균 정확도는 g4b best 66.24%, g6 66.73%, g3 63.51%, 조합 **70.36%**였다. g4b 대비 +4.11%p(95% 구간 [+2.01,+6.18]%p). 이미 평가된 recipe·셋의 재측정이며 새로운 독립 시험의 성공으로 부르지 않는다. 기존 엔진 1,335문항 재로딩 예측 불일치 0개, 추가 추론 없는 단일 checkpoint다. [모델·근거·한계](g6-soup-replication.md).
- **고정 조합의 새 문항 확인(2026-10-19):** 위 67:33 비율을 바꾸지 않고 기존 fresh·JEVal와 원본/구성 모델의 실제 학습 **1,299,919행** 및 gold dev 지문을 제외했다. 같은 원천 과제군에서 남은 새 **1,847문항/10출처**의 출처 평균 정확도는 g4b **65.39%**, 조합 **71.97%**, 차이 **+6.58%p**(95% 구간 **[+4.61,+8.58]%p**)였다. 182회 회복·57회 악화. 이 새 문항은 recipe 선택에 쓰지 않았다. 의미 수준의 모든 근사 중복까지 검사한 것은 아니다. [새 문항 감사·수치](g6-soup-holdback-results.json).
- **소규모 원본 보존 학습·추론 조합(2026-10-19):** 전 층 rank-8 LoRA의 CE/CE+순열 JSD를 두 seed로 256 update씩 학습하고 업데이트 평균·원본 혼합·cyclic 평균·top-4 재비교·gold memory를 비교했다. 별도 2,998문항에서 기본 80.83%, 단일 adapter soup 80.64%, cyclic soup 81.14%, shortlist 81.06%. 세 비교의 보정 구간이 모두 0을 포함해 이 추가 방법들은 개선으로 채택하지 않았다. [설정·전체 결과](robust-combinations.md).
- **Transformer 내부 블록 반복(2026-10-19):** 중간 4개 hybrid 블록을 공유해 한 번 더 실행하는 24→28블록 경로를 추가했다. 동일 g4b 출발점에서 기본·반복 구조 모두 전체 언어 백본을 512 update·8,192표본으로 학습했다. 이전 학습·평가 입력 그룹을 제외한 새 확인 8,823문항/77출처에서 기본 **75.20%**, 반복 **75.29%**. 차이 **+0.10%p**, 문서 bootstrap 95% 구간 **[−0.20,+0.45]%p**로 개선은 확인되지 않았고, 추론은 **15.27%** 느렸다. 가중치/예측 평균은 사용하지 않았다. [구조·학습·결과](recurrent-depth.md).
- **후보별 판정 Query의 실제 학습(2026-10-19):** 앞 23층·전체 K/V를 유지하고 마지막 attention·FFN·LM head를 K개 조건부 Query에 재사용했다. 새 adapter 262,144개, 같은 g4b·데이터·512 update/배치16·전체 언어 백본 학습으로 기본/단일 Query/후보 Query를 비교했다. 기본 대조군은 직전 실험의 동일 fit을 검증해 재사용했고 새 두 fit의 전 512개 입력 hash가 일치했다. 새 **3,394문항/35출처/2,022그룹**에서 출처 평균 기본 **70.70%**, 단일 **70.72%**, 후보 **70.75%**. 후보 대 기본 **+0.046%p**, 95% 구간 **[−0.328,+0.412]%p**, 28회복/25악화로 개선을 확인하지 못했다. 학습 후 GPU 계산은 약1.3% 짧았지만, 동일 가중치로 경로를 번갈아 측정한 실제 엔진 호출은 8.5873→8.6548초로 약0.79% 길었다. 정확도·전체 호출 비용 양쪽의 우위를 얻지 못했다. 저장·구조 복원·기존 엔진 연결 포함. [구조·통제 조건·결과·한계](decision-native-next.md), [원문 수치](decision-tail-trained-results.json).
- **중간 블록 delta 재사용(2026-10-19):** 4개 native 층이 만든 변화량을 token-wise depth attention으로 다시 읽는 0게이트 경로10,240개를 추가했다. 원래24층은 각각1회만 실행하며, 같은 g4b·512 update·8,192개 입력·전체 언어 백본 학습으로 검증한 native fit과 비교했다. 초기4,147문항 예측/확률 차이0, 전512개 입력 hash 일치. 새 **2,220문항/18출처**에서 기본 **65.70%**, 새 구조 **65.85%**, 차이 **+0.154%p**, 95% 구간 **[−0.282,+0.576]%p**, 19회복/13악화로 개선을 확인하지 못했다. 같은 가중치의 native/새 경로 엔진 호출은8.5956→9.0624초(+5.43%)였다. 저장/엔진 재현성 검증과 관련55개 테스트를 통과했으며, 진단상 실제 이전층 delta를 선택해 쓰고 있었다. [전체 결과·감사·provenance](delta-memory-results.json), 상세 구현/해석은 [실험 로그](v3-log.md).
- **구조 후보 상태(2026-10-19):** 위 delta 재사용은 사용자 요청으로 채택 후보에서 제외했다. 후속 [중간 층의 가설 작업공간](hypothesis-workspace.md)은 앞16층 뒤 후보 상태를 추가해 상위8층에서 원문·가설을 공동 갱신한다. 같은g4b·512update·전체언어학습·같은8,192개입력의 선택셋4,147문항/77출처에서 기본75.7419%, 새75.7470%(+0.0050%p)였다. 가설에서만 직접 score하는 두 번째 버전은 같은256스텝에서73.1286% 대 기본73.9417%(−0.8131%p)로 사전 규칙에 따라 중단했다. 두 버전 모두 채택하지 않고 새 확인셋을 열지 않았다. 두 번째는 선택지 성분 제거 시512문항 중33개의 선택이 달라져 실제 경로 영향을 확인했지만, 준비된 GPU 입력은2.70% 느렸다. 관련63개 테스트와 두 저장 모델의 전체선택4,147문항 복원이 통과했다. [잠재 작업공간·post-Transformer 연구 조사](../papers/latent-workspaces.md)와 구체적 한계를 함께 기록했다.
- **BDH 상위층 교체와 데이터 양(2026-10-19~20):** 뒤8개 native 층을 실행하지 않고 앞16층 뒤 양방향·self 제외 연상 메모리/coactivation을3회 갱신한다. 원래 코드 head를 유지하고 모든 사용 언어 파라미터를 학습했다. 세 군1,024 update·16,384노출·동일 출처 순서에서, 기존 선택셋4,147문항/77출처의 원본16,384행75.5504%, BDH16,384행74.9540%, BDH4,096행4회73.2656%였다. 큰 데이터의 구조 차이−0.5964%p로 채택 기준에 미달했고 새 확인셋을 열지 않았다. BDH의 고유 문항4배는+1.6884%p로 이 실험의 데이터 다양성 효과를 보였다. 전체 gold6파일699,960행과 실제 구조 적응에 쓴 행 수를 구분하며, native_small이 없는 한 seed·세 군 비교다. 공개 BDH를 응용한 별도 구조이며 BDH-CQ 비공개 구현의 재현이 아니다. [실제 구조·학습곡선·조건과 한계](bdh-memory.md).
- **학습 예산 확대(2026-10-20):** 원본·BDH·블록 반복·가설 출구를 같은 65,536행·4,096 update로 다시 비교했다. 원본 79.14%, BDH 78.16%, 블록 반복 79.05%, 가설 출구 78.45%로 원본을 넘은 구조가 없다. 원본 오답의 75%를 네 구조가 모두 틀렸고 그중 90%는 같은 오답이었다. [결과](long-training.md).
- **이후 구조·손실 실험(2026-10-20~23):** DeltaNet 역방향 scan −0.51%p, DUMA/Theseus 3종 모두 원본 미만, 증거 쌍 손실·단일 forward 의미 매칭·Talking-Heads는 모든 구간이 0을 포함했다. MNTP는 사용자 요청으로 중단했다. 새 경로를 꺼도 예측이 거의 바뀌지 않았고, seed만 바꾼 원본끼리의 예측 변화(1,280문항 중 106~133개)가 구조 변경에 따른 변화(7~21개)보다 컸다. [작업 기록](v3-log.md).
- **학습 레시피(2026-10-23):** 같은 입력·순서에서 EMA −0.54%p, 구간 평균 −0.57%p, LR 1e-5 −3.76%p. [설계·해석](recipe-ema-lr.md).
- **장문과 질문 우선 배치(2026-10-23~24):** 공개 장문 테스트 5종과 25% 장문 학습 풀(자르지 않음)을 만들고 native/echo를 3 seed 비교했다. 장문 점수 +1.59/+0.95/−0.71%p, 평균 +0.61%p, seed×문항 95% [−0.84, +2.07]로 사전 등록 기준 실패. 원본의 찾기 과제는 이미 98~100%이고 실패는 다단계 추론(BABILong 0k qa3 18%)·다예시 분류(TREC류 36~48%)에 몰려 있다. 이전 100개 출처 풀이 QuALITY·MuSiQue·kv-lookup·API-Bank를 빠뜨렸던 것도 이때 확인했다. [설계·결과·원인](long-context-echo.md).
- **d3-lite 가중치 감사:**
  - readout은 원본 LM head 행에서 1.1%만 이동했다. 임베딩은 67% 원소가 바뀌었다(앞선 "동결" 추정은 틀렸다).
  - g1은 d3-lite보다 층마다 1.5~2.4배 더 이동했다.
- **순서 편향:** 위치 쏠림은 작다(RStd 0.02~0.04). 4순서 평균의 효과는 1%p 남짓이다.
- **망각과 학습:** 원본 대비 d3-lite와의 순증 차이 대부분은 "덜 새로 맞힘"이다(g1: 212 대 77). 섞기 뒤에는 잊음이 d3-lite 이하로 내려간다.
- **반복 학습:** g3 3에폭에서 dev 손실이 오르고, 틀린 문항을 90% 넘게 확신하는 비율이 5% → 46%로 늘었다. 새 문항으로 1바퀴 돈 g4b에는 이런 양상이 없었다.
- **같은 출처인데 덜 일반화:** WinoGrande는 내부 dev 0.85인데 JEVal 정확도는 0.63이다. 선택지 형식(키 대 설명)은 원인이 아니었다(`format_probe.py`).
- **무관한 선택지 패딩:** 입력 토큰의 약 40%를 차지한다. 패딩을 끈 g4b는 공개 다지선다(SGD, BANKING77, API-Bank)가 떨어졌다. 다만 데이터도 함께 바뀌어 g4a로 확인할 일이다.
- **남은 new 격차(기존 g4b/g3 후보 대 d3-lite):** 금융 예/아니오, 개체 연결(AIDA), 예시 기반 분류(LongBench TREC), 커뮤니티 선호. 중국어 과제와 장문 검색은 동률이고, 여론·가치 판단은 앞선다. 완료된 g6 계열 전체의 최신 격차를 뜻하지 않는다.
