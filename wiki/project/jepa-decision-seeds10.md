2026-11-04. **10seed(3조건×10개) 학습·평가·독립 검산 완료.** 기존3seed 결과·checkpoint·검산은 원래 디렉터리에 보존한다.

10seed에서 good의 회전 후 이미지 seen 정확도는 CE보다 평균 **+4.81%p** 높았다.
95% 구간은 [−0.55,+10.21]%p라서 CE보다 정확도가 높다고 확정하기에는 불확실성이 남는다.
good−bad의 같은 지표는 **+8.37%p [3.79,12.53]**로, 이 설정에서는 view 구성의 효과를 지지한다.
이미지 NLL도 CE 대비 감소했다. 이 결과만으로 논문의 정렬 정리나 일반 Decision 성능 향상을 입증하지는 않는다.

텍스트 seen은 CE94.25%, good93.88%로 평균 차이 −0.36%p [−4.07,+3.18]였다.
텍스트 unseen은 두 조건 모두 평균이 낮고 seed 편차가 크다.
텍스트 성능의 향상·하락·동등성 중 어느 것도 확정하지 않는다. 원래3seed에서 보였던 텍스트 하락을
전체10seed의 일관된 결과로 일반화할 수 없다.

## 질문과 고정 조건

원 실험은 CE 대비 good-view의 회전 후 이미지 seen 정확도가 +6.15%p였지만,
3seed 차이가 +7.54,+17.47,−6.56%p로 흔들렸다. 평균의95% 구간은 [−5.55,+16.92]%p였다.
현재 설정에서 그 평균 효과가 반복되는지 seed를 늘려 확인한다.

**텍스트와 이미지 모두 평가한다.** 텍스트는 색·모양·위치 합성 장면의 설명문을,
이미지는 그 장면의 렌더링을 입력한다. 두 입력 모두 같은 학습된 상태 인코더와 판정기를 쓴다.
seen은 학습한 질문 signature, unseen은 학습에서 제외한 질문 signature이고, 모두 새로운 test 장면이다.
이 점수는 해당 합성 문제의 성능이다. 일반 자연어 벤치마크 성능과 구분한다.

원본 Qwen 앞단은 고정한다. 실제 답의 유일한 입력인64차원 상태를 만드는 공유 인코더와
구조화된 판정기를 학습하며, CE / CE+bad / CE+good의 세 조건을 유지한다.
데이터·view·loss 계수·모델 구조·optimizer·200epoch·checkpoint 선택 기준을 변경하지 않았다.
학습된 단일 checkpoint가 각 평가에 답한다. 보고하는 평균은 독립적인10회 학습의 성능 평균이다.

## 실행 전에 고정한 seed

| 구분 | seed |
|---|---|
| 기존3개 | 401,419,443 |
| 추가7개 | 461,479,503,521,541,563,587 |

각 seed마다 CE/bad/good를 모두 학습한다. 총30개 조건 중 기존9개 checkpoint는 그대로 재사용하고,
21개를 추가 학습한다. 두 개의 별도 Python process에서 실행하며, 학습 함수는 원본 그대로 호출한다.
모든 조건의 초기 가중치 해시와1,600개 batch 순서를 seed별로 대조한다.
text seen validation NLL이 가장 낮은 checkpoint를 고른다.

결과를 보고 seed 수를 조절하거나, 성능이 낮은 seed를 빼거나, unseen/test로 checkpoint를 고르지 않는다.
중간 실패가 생기면 attempt 로그를 보존하고 같은 설정으로 재시도한다.

## 평균과 불확실성

각 seed에서 good−CE와 good−bad 차이를 짝지어 계산한다.
과제별 정확도·NLL의 macro 평균, 원래의 train-only 평균/직교회전/보조 scale/잘못된 쌍20개 대조를 모두 유지한다.
신뢰구간은10개 seed와256개 test 세계를 각각 복원 추출하는 bootstrap5,000회다.
평가 소스에서는 seed 목록과 bootstrap의 seed 추출 개수만 확장했다.
AST 검사로 그 외 평가식이 원 실험과 같음을 확인했다.

주 결과는 전체10seed다. 이미 본 기존3seed와 추가7seed의 평균도 따로 남긴다.
동일한 이미 살펴본 합성 test 분할에서 반복한 결과로, 새로운 분포에서의 독립 확인 실험으로 부르지 않는다.
여러 지표의95% 구간은 각각의 구간이며 복수 비교 보정을 적용하지 않았다.

텍스트 seen95%·unseen90% 점검은 동일하게 유지한다. 평균과 더불어 seed별 통과 횟수도 보여 준다.
텍스트 자체가 못 푸는 질문의 이미지 결과를 정렬 하나의 효과로 해석하지 않는다.

완료 검산은30개 checkpoint의 상태, train-only 정렬, 정답, 조건별 판정과 집계, bootstrap 구간을 확인했다.
조건별30×25회, 총2,304,000개 질문의 판정을 재검산했고 저장된 정답 개수와 불일치는0이었다.
다만 검산용 FP64 확률식과 실제 FP32 실행의 argmax가 거의 동점에서5번 달랐다.
해당 답 사이의 최대 log 확률 차이는2.03×10⁻⁸이었다. 실제 FP32 실행의 선택을 정확도 기준으로 유지하고,
모든 유효 후보의 log 확률을 독립 계산과 대조했다(최대 오차2.87×10⁻⁶ 미만).
원 점수·checkpoint는 수정하지 않았다. 실패한 첫 검산 로그와 수정 전 검산 소스도 실행 디렉터리에 보존했다.
Qwen 특징 bank 생성 자체를 독립적으로 반복한 것은 아니며, 해당 파일·소스·기본 가중치는 해시로 확인했다.
