# d3-lite를 넘기 위한 전략

[위키 홈](../README.md) · [목표와 규칙](../project/jev-index.md) · [작업 기록](../project/v3-log.md)

**상태: 진행 중(2026-10-18 갱신).** 측정된 내용은 [작업 기록](../project/v3-log.md)과 [v3 요약](../project/v3-summary.md)에 있다. 아래 이득 수치는 추정이다.

## 원칙

- 점수의 80%가 비공개다. checkpoint와 변형은 **대리셋(JEVal)과 d3-lite 맞대결**로 고른다. 공개 점수로 고르지 않는다.
- 공개 벤치마크 과적합(OneJev 0.8B: public 42.7, new 16.8)은 피한다. 같은 역량의 **다른 데이터**와 넓은 도메인 데이터로 일반화를 지킨다.
- 모든 학습 데이터는 [오염 필터](../project/v3-log.md)를 통과해야 한다.

## 구조 비교: attention 변형

| 변형 | 구성 | 근거와 위험 |
|---|---|---|
| ① | causal (원본) | 대조군 |
| ② | full-attention 6층 양방향 (d3) | 검증된 설계 |
| ③ | ② + 질문·선택지를 state 앞에 반복(`echo`) | causal DeltaNet도 질문을 알고 지문을 읽게 됨. 구조 변경 없이 토큰만 늘어남 |
| ④ | ② + DeltaNet 역방향 scan(가중치 공유, 채널별 gate 0 초기화) | 0.8B 유지. gate=0에서 ②와 동일하게 출발. 적응 데이터가 부족할 위험 |

[후보 독립 attention](../papers/candidate-independent-attention.md)은 보류했다. Qwen3.5에서는 DeltaNet·conv 경로 때문에 mask만으로는 격리되지 않는다. LM 코드 readout도 포기해야 하고, 해당 논문에서도 OOD 정확도가 떨어졌다. 순서 강건성은 순열 평균으로 대신한다.

**(2026-10-16 밤 중단: ①과 ②가 같은 500스텝에서 dev 0.69/0.66, ood 0.72/0.75로 거의 같아 ②로 확정하고 ③④는 취소했다.)** 비교 조건: Jev 코퍼스만으로 ②를 돌렸더니 지식 손실이 커서, 이 조건의 비교는 의미가 약하다고 판단했다([작업 기록](../project/v3-log.md)). 그래서 **Jev 50% + 2차 데이터 50%**, 6.4만 행, 2,000스텝, 같은 하이퍼파라미터로 네 변형을 비교한다. 이긴 구조는 더 많은 데이터로 길게 다시 학습한다(당시 계획의 교사 label은 2026-10-17 방침으로 폐기).

## 지금까지 알게 된 것 (2026-10-18)

- **구조는 핵심 변수가 아니다.** causal과 양방향이 같은 500스텝에서 거의 같았다.
- **정답 전용 1바퀴(g1)는 d3-lite에 못 미친다:** 공개 샘플 33.68 대 39.65, JEVal dev 0.348 대 0.482.
- **원본과 섞으면 대리셋이 크게 오른다.** 새 분야는 d3-lite 수준까지 회복된다. 섞기의 최적 비율은 대리셋과 공개 점수에서 다르다.
- **위치·코드 편향은 격차의 원인이 아니다.** 순서 평균 효과도 작다.
- **격차의 큰 몫은 덜 새로 맞힌 것이다(212문항).** 더 잊은 몫은 77문항이다. 다만 원인이 학습량인지 데이터 구성·학습 방식인지는 아직 모른다.
- **반복 학습은 과적합한다.** g3 3에폭에서 dev 손실이 오르고, 틀린 답을 90% 넘게 확신하는 비율이 5%→46%로 늘었다. 에폭이 늘수록 공개 점수는 오르고 JEVal new는 내린다.
- **새 문항으로 1바퀴가 낫다.** g4b(40만, 패딩 없음)는 fresh 0.413→0.484, JEVal same 0.470→0.522로 올랐다. 공개 다지선다는 떨어졌다(패딩 효과 확인 필요).
- **서로 다른 학습의 평균이 장점을 합친다.** Soup g4b + g3 e2는 공개 39.80(d3-lite 39.65), fresh 0.483(0.498), JEVal same 0.548(0.583)이다. 남은 큰 격차는 JEVal new(0.363 대 0.409)다.
- **데이터 폭이 new 격차를 줄였다(g6, 2026-10-19).** 104개 출처 70만 행 1바퀴로 JEVal 0.465(new 0.397), 공개 40.28을 얻었다. g6 0.67 + g3e2 0.33은 공개 43.12·fresh 0.520으로 d3-lite를 넘고, g6 + g4b는 JEVal 0.476(new 0.411)이다. JEVal 차이는 ±0.01 잡음 범위다.
- **병합 방법보다 재료가 중요하다.** TIES·DARE·LiNeS·Model Stock은 단순 가중 평균보다 낮았다.
- **new 격차는 분야에 몰려 있다.** 금융 예/아니오, 개체 연결, 예시 기반 분류, 커뮤니티 선호에서 크게 지고, 중국어·장문 검색은 동률이며, 여론·가치 판단은 앞선다.
- **dev 신뢰도:** 내부 dev에 문서 단위 누수가 있었고 고쳤다. 지금은 원본 항목 키, 문서 키, 근사 중복으로 묶어 분할한다. HoVer(같은 근거 문서의 다른 주장) 등 일부 잔여가 있다.

## 다음 단계

1. 남은 확실한 격차(금융 예/아니오, BoolQ·WinoGrande·CommonsenseQA)를 데이터로 보강한다. 7차 데이터(`v3-gold7`: 시 최소쌍, MiniCheck, 입장, CommonsenseQA 2.0)가 준비돼 있다.
2. 패딩 효과를 확인한다(g3e2를 섞으면 공개가 오르는 이유가 패딩 학습인지).
3. 최종 후보는 JEVal restricted로 한 번만 확인한다. fresh-v1도 함께 본다.
4. 제출 전: 라이선스 검토, 공개 suite 전체 실행(`complete: true`), 학습 데이터 공개 문서 작성.
