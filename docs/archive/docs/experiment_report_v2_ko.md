작성: 2026-10-11. 설계와 미리 정한 성공 기준은 [v2 설계](v2_plan_ko.md), v1은 [v1 실험 기록](experiment_report_ko.md)에 있다.

## 요약

- **64개 선택지:** 해결됐다. 선택지 60~64개 test에서 정답 코드가 `AA–BL`인 문항의 적중률이 89.9%로 `A–Z` 구간(91.4%)과 거의 같다. v1은 같은 구간에서 0.0%였다. KMMLU 45개 분야는 v1 14.85%에서 v2 26.43%가 됐다.
- **새 과제:** 크게 좋아졌다. 질문 유형(noul, score), 장문 외 새 17개 test 평균이 v1 52.51%에서 v2 82.89%가 됐다.
- **v1 과제:** 떨어졌다. 16개 과제 평균이 v1 76.95%에서 v2 74.76%로 2.19%p 낮다. 하락은 지식·독해형 객관식(ARC −8.66, CSQA −8.27, MMLU-Pro −4.77, RACE −4.62%p)에 몰려 있고, 미학습 객관식 OpenBookQA(−9.4%p)와 HellaSwag(−3.4%p)에서도 v1의 개선이 사라졌다.
- **보정:** v2는 보정 전부터 test ECE 0.0149로 이미 잘 맞았다. temperature 보정이 개선할 여지가 거의 없었다.
- **상태 공유:** 질문 8개를 묻는 장문에서 같은 결과를 5.7배 빠르게 낸다.

미리 정한 5개 기준 중 3개를 통과했다.

> **추가 분석(2026-10-11, 아래 "v1 과제 하락의 원인 분석" 절):** 위 v1 과제 하락의 대부분은 모델 선택에서 나왔다. v1 결과는 두 seed의 가중치 평균 모델이고, v2는 seed 하나의 체크포인트가 선택됐다.
> - v2의 두 seed 평균 모델은 v1 과제 평균 76.45%로 v1과 0.50%p 차이다. 새 과제(83.97%)와 64개 선택지(`AA–BL` 정답 91.8%)는 선택된 모델보다 좋다.
> - 남은 유의한 하락은 ARC −2.5, CSQA −3.1, CoLA −3.7, OpenBookQA −4.6%p다.
> - 이 비교는 test를 본 뒤의 사후 분석이다. 평균 모델을 정식 v2로 채택하려면 선택 규칙을 먼저 바꾸고 개발 데이터로 정당화해야 한다.

## 해석

**확인된 것**
- 선택지 수와 코드 범위를 학습에 포함하면 v1의 45개 붕괴가 사라진다. v1 조사에서 세운 가설("임베딩 손상이 아니라 학습 분포 문제")과 맞는다.
- 상태 공유는 재학습 없이 결과를 거의 바꾸지 않고 장문 다중 질문을 5배 이상 빠르게 한다.

**확인되지 않은 것: v1 과제 하락의 원인**

지식·독해형 객관식과 미학습 객관식의 하락은 이번 실험만으로 원인을 분리할 수 없다. 후보는 다음과 같다.
- **추가 미세조정에 따른 사전학습 지식 손실.** v2는 v1보다 1.7배 많은 update를 했고 늘어난 대부분이 분류형 과제다. 지식이 필요한 ARC·CSQA·OpenBookQA에서 하락이 크고, 분류형 과제는 유지됐다는 패턴과 맞는다.
- **코드 배정 방식 변경.** v1은 100% 섞인 코드, v2는 60% 순서대로 코드였다. 다만 위치 편향 증가는 관찰되지 않았다.
- **"해당 없음"·주입 증강, 과제 혼합 비율 변화.** 객관식 예제를 보는 횟수는 seed 41 기준 v1과 같다(각 1회).
- **모델 선택.** v1은 두 seed 평균, v2는 seed 41 단독 체크포인트가 선택됐다. 개발 표본에서 둘의 차이는 2문항 수준이다.

## v1 과제 하락의 원인 분석

웹 문헌 조사(망각, 데이터 구성·형식 효과)와 저장된 산출물로 가설을 하나씩 확인했다.

### 확인한 결과

| 가설 | 확인 방법 | 결과 | 판정 |
| --- | --- | --- | --- |
| 모델 선택(평균 대 단독 seed) | v1·v2 각 seed 최종 모델과 평균 모델을 같은 객관식 17,387문항에서 비교 | 객관식 8개 묶음 평균: v1 seed 53.68 / 52.10, **v1 평균 58.41**; v2 seed 52.60 / 51.67, **v2 평균 57.01** | **주 원인** |
| 코드 형식(순서대로 대 섞기) | v1·v2를 v1 학습 형식(섞인 코드)으로 다시 채점 | 두 모델 모두 1%p 안쪽 변화(v2 ARC 67.8 → 68.2) | 원인 아님 |
| 위치 편향 | 객관식 예측 위치 분포를 정답 분포와 비교 | v1과 v2 모두 정답 분포와 가깝다(ARC 첫 위치 예측 26.0%, 정답 25.3%) | 원인 아님 |
| 순서 일관성 하락의 원인 | 자신의 top-2 확률 차이 구간별로 일관성 비교 | 모든 구간에서 v2 ≥ v1. 확신도가 낮은 문항이 많아진 결과다 | 형식 문제 아님 |
| 원본 상태로의 복귀(spurious forgetting) | v1과 답이 다른 문항에서 v2가 원본과 같은 답을 고르는 비율 | ARC 29%(v1 45%). v1만 맞힌 문항에서는 20.1%로 우연 25%보다 낮다 | 지지하지 않음 |
| 원본에서 더 멀어짐 | 선택지 분포 기준 KL(모델‖원본) | v2가 v1보다 더 멀지 않다(OpenBookQA 0.41 대 0.55) | 지지하지 않음 |
| 표면 단어 겹침 지름길 | 질문과 단어가 가장 많이 겹치는 오답을 고르는 비율 | v2가 v1보다 1~5%p 높다(ARC 10.7 → 14.0%). ARC 전체로 환산하면 약 0.5%p | 약한 기여 |
| "해당 없음" 증강의 보기 수 누출 | 학습 코드 검토 | 정답을 빼면 k개, 남기면 k+1개를 보여 줘서 보기 수가 고정된 과제에서는 정답이 샌다 | 결함 확인, 영향 크기 미측정 |

### 해석

- 같은 출발점에서 학습한 두 모델의 가중치를 평균하면 지식·독해형 객관식이 약 4.5%p 오른다. v1과 v2 모두 그렇다.
  - 미세조정 한 번은 seed와 데이터 순서에 따라 고유한 방향으로 치우치고, 평균하면 이 치우침이 상쇄된다. 문헌의 WiSE-FT, model soup, LM-Cocktail, 정렬 비용(alignment tax) 연구의 결과와 같은 방향이다.
  - 분류형 과제는 평균 여부에 거의 영향을 받지 않는다.
- v2에서 단독 체크포인트가 선택된 이유는 개발 표본에 있다. 평균 모델과의 차이가 832문항 중 2문항(0.24%p)이었고, 객관식은 26개 과제 중 5개(160문항)뿐이라 ±4%p 노이즈에 묻혔다.
- 평균 모델끼리 비교해도 남는 하락(ARC −2.5, CSQA −3.1, CoLA −3.7, OpenBookQA −4.6%p)의 원인은 분리되지 않았다. 후보는 다음과 같다.
  - 객관식 학습 비중 감소(40% → 23%)와 새 분류형 과제의 부정적 전이. 문헌에서는 패러프레이즈·분류형 중간 과제가 추론 과제에 부정적으로 전이된다는 보고가 있다.
  - "해당 없음" 증강의 보기 수 누출.
  - 무작위 오답으로 생긴 유사도 지름길.

### 다음 실험

1. **선택 규칙을 먼저 고정한다.** "두 seed 평균을 기본으로 한다"를 미리 정하거나, 객관식 개발 표본을 과제당 300개 이상으로 늘린다. 그 뒤 평균 모델을 정식 v2로 채택하고 보정값을 다시 맞춘다.
2. **v1·v2 가중치 보간과 seed 추가 평균.** 학습 없이 남은 하락을 줄일 수 있는지 본다.
3. **요인 하나씩 제거한 학습:** "해당 없음"을 고친 버전, 객관식 비중을 올린 버전, 어려운 오답을 쓴 버전.

## 다음 단계 제안

1. **가중치 보간 (학습 없음).** v2와 v1, 또는 v2와 원본 가중치를 섞은 모델(WiSE-FT 방식)을 평가한다. 64개 선택지 능력을 유지하면서 객관식 성능을 회복하는지 가장 싸게 확인할 수 있다.
2. **원인 분리 학습.** 학습률을 1e-5로 낮추거나 객관식 비중을 높인 짧은 학습을 하고, 코드 배정 비율(순서대로 60% vs 섞기 100%)만 바꾼 학습도 비교한다.
3. **QuALITY 장문 학습 재설계.** 지금은 효과가 없었다. 장문 비중, 입력 길이별 성능, 원본 대비 하락 원인을 따로 본다.
4. **다른 공개 모델과 비교.** Jeff·Decider 0.8B 등 같은 기반 모델과의 비교는 아직 하지 않았다(설계 문서의 미적용 항목).

```python
from scorer_v2 import DecisionScorer

scorer = DecisionScorer("/home/khkim/qwen-decision/training/text-decision-v2/model")
result = scorer.score({
    "state": "I was charged twice for one order and the app crashes when I open receipts.",
    "questions": {
        "route": {"type": "choice", "question": "Which team should handle this first?",
                  "options": {"billing": "Charges and refunds", "technical": "App errors", "sales": "New purchases"}},
        "refund": {"type": "noul", "question": "Is the customer asking for money back?"},
        "urgency": {"type": "score", "question": "How urgent is this request?",

    },
})
```

- 질문이 2개 이상이면 상태를 한 번만 읽는다(`share_state=False`로 끌 수 있다).
- 선택지는 2~64개이고, 65개 이상이면 거부한다. 입력은 자르지 않는다.
- 텍스트 전용이다. 이미지 입력은 v2에서 학습·평가하지 않았다.
